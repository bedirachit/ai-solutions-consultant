# Slide patterns

| Pattern | Use for | Layout |
|---|---|---|
| Cover | Title, client, date, confidentiality | Title, subtitle, presenter, date; optional scope panel |
| Executive summary | The whole argument on one page | 3–5 numbered rows: bold message + one supporting line |
| Situation / complication | Why act now | Two columns or a short narrative with 2–3 facts |
| Scope cards | What's in scope | 3–5 equal cards: tag, capability, one line, systems touched |
| Layered architecture | Target architecture for executives | Horizontal layers (channels → interaction → AI → integration → systems of record); new layer highlighted |
| Current vs proposed | Process change | Two columns of numbered steps; proposed column highlighted |
| Process flow / chevrons | End-to-end journey | 4–6 numbered step cards left to right; new step highlighted |
| Integration table | What each system exposes | System / role / access / pattern columns; access level emphasized |
| Options comparison | Choosing between alternatives | Table with weighted criteria; recommendation highlighted; or 2×2 |
| Controls grid | Risk and security | 2×3 cards, each a control with one line |
| Benefits / business case | Value | Big numbers with basis and source (placeholders if unknown) |
| Roadmap | Phasing | Horizontal timeline of phases with scope and exit criteria |
| Risks and mitigations | Risk register summary | Table: risk, impact, mitigation, owner |
| Decisions requested | The ask | Accent background; 2–4 numbered decisions with owners and dates |
| Appendix: detailed diagram | Physical / network detail | Full-bleed exported draw.io image with legend |

## Writing action titles
- Bad: "Architecture overview". Good: "The AI platform sits as one new layer between existing channels and systems of record".
- Bad: "Risks". Good: "Six controls are built into the design, so risk is managed from day one".
- Keep the subject, verb and consequence; avoid "It's not X, it's Y".
