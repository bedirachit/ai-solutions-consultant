# AI Solutions Consultant — Claude plugin marketplace

This repository is a Claude plugin marketplace containing one plugin, **ai-solutions-consultant**: a consulting team in a plugin (discovery, understanding document, CSP-specific architecture in draw.io with official icons, executive decks) with an MD / Senior Partner agent that reviews and approves every artifact.

See [plugins/ai-solutions-consultant/README.md](plugins/ai-solutions-consultant/README.md) for what it does and how to use it.

## Install

- **Claude Cowork / claude.ai:** add this repository as a plugin marketplace in your plugin settings, then install **ai-solutions-consultant**. Or open the `.plugin` file shared by the author in the Claude desktop app.
- **Claude Code:** `/plugin install ai-solutions-consultant --marketplace bedirachit/ai-solutions-consultant`

Connect the **draw.io** connector for inline diagrams and official icon search.
